
# RAG搭建第一次尝试记录

> 从零开始的RAG探索之路

---

## 3月20日 - Cherry Studio 初体验

### 上午完成基础模块

- 下载安装 Cherry Studio
- 用 Ollama 部署 Bge-M3 嵌入模型
- 配置 DeepSeek R1 大语言模型
- 找到知识库所需资料

### 开始搭建RAG框架

Cherry Studio 属于入门级 RAG 搭建平台，可视化操作界面，对新手非常友好。按照指引，很快创建了知识库并同步对接了大语言模型。

### 第一次对话测试

没有多想，就发起了第一次对话，与此同时 CPU 开始高速运转，风扇转得嗡嗡响，内存占用率达到99％，这绝不是夸张描述。

等了好几分钟才返回一串看不懂的英文字符，虽然看不懂内容，但是红色字体也能猜到是错误提示。

### 问题排查

把结果 copy 给 DeepSeek，说是嵌入的文档识别不了，没有向量化成功，因为文档压根没上传成功。又按照指引把文档提取成嵌入模型可识别的格式，这看似简单的操作也花了大半个小时。

### 初步成功

转换过的文档重新上传知识库，这也是很简单的事情，但是也等了好一会才嵌入完成。问了 DeepSeek 才知道，8G 内存的电脑用 Bge-M3 只能是这种效果。

它建议改用轻量的嵌入模型，为了先把流程走通，还是继续用 Bge-M3。

等嵌入完成之后，再次发起对话，这一次不出所料，检索时间还是那么久，如此简单的测试环节，已经是 8G 内存电脑的极限了。

庆幸的是返回结果是正确的，到此，整个 RAG 的基础框架算是完成了。

### 成就感与反思

其实当时挺开心的，很有成就感，证明花了几天备考的 CAIE 证书没有白考。

现在看来，是我想多了，RAG 的基础搭建仅仅是开始，最主要的检索生成环节，才是整个 RAG 的灵魂。

### 继续探索

为了让这个 RAG 达到能够使用的程度，又往知识库导入更多的数据。导入要十来分钟，检索又要十来分钟，这样效率很慢。

而且这样继续下去，那破电脑指不定会在哪一天突然宕机。

出于这样的考虑，又找 Deepseek 推荐其他的嵌入模型，换成更轻量的嵌入模型，发现实际检索效率并没有提升。再问 Deepseek 是什么原因，才知道大语言模型也会影响检索效果。

### 腾讯云尝试

Deepseek 又给我推荐用云端来搭建 RAG，当时选用的是腾讯云 ADP，因为新用户有免费试用额度。

有了本地搭建 RAG 的前车之鉴，云端 RAG 的搭建只用了十来分钟，不过操作界面跟 Cherry Studio 有很大的不同，实测效果也不同。

### 云端RAG的问题

因为腾讯云的 RAG 不占用本地资源，检索生成效率显著提高，但是准确率还是很不理想，幻觉太明显，让人没有用下去的想法。

找 Deepseek 要解决幻觉提高准确率的方法，又是一整捣鼓更换提示词，修改分块大小。再经过多轮对话测试，发现效果不明显。

### 误操作

最后因为误操作了知识库内文档转换成问答，导致试用的额度全部用完，腾讯云的 RAG 部署就到此为止。

倒也不是我不想为 RAG 的搭建多花一分钱，只是搭建平台还有很多可以选择。

### 新的认识

最主要的是虽然掌握了 RAG 本地搭建跟云端搭建，但是发现实测效果还不如直接问大厂的语言模型，所以对搭建 RAG 这件事的价值有了很大的问号。

为此，又找了 Deepseek。它直接了当回复我，说不完善的 RAG 确实不如成熟的大语言模型，但是大语言模型毕竟不是万能的，也有幻觉，对于某些领域的专业性问题，也没办法检索到。

而且大语言模型的知识库并不是实时更新，对于当下发生的事情它并不知道。

简而言之，搭建 RAG 还是有其价值所在，当解决了明显的幻觉，提高准确率，完善的 RAG 是可以成为提升效率的工具。

有了这样的理念，又投身于其他平台的 RAG 搭建中，尝试过 dify、langchain，还有 anythingllm。

## 3月26日 - Ollama下载困境

### 奇怪的下载问题

羊驼 loge 的 ollama 光是下载就耗费几个小时的时间，说来也奇怪，前段时间下载的 ollama 十几分钟就好了。

一开始还以为我网络的问题，今天在其他设备下载才发现是 ollama 的问题，这玩意儿是在国外的节点。

### 工具尝试

#### Dify 部署失败

一开始打算用 dify 来做本地部署，前置条件是要先下载 Docker Desktop，下载好了，发现安装之后要重启才能生效，重启肯定不行，网吧的电脑重启都没了。

#### ChatRTX 放弃

Deepseek 又推荐用 ChatRXT，这玩意儿也难搞，根据指示在官网找了半天没找到，又下载 NVIDIA APP，也没有安装入口，找了一个多小时，遂放弃，到现在也没找到安装包的入口。

#### AnythingLLM 安装卡住

后面又选择用 AnythingLLM 做本地部署，下载顺利，到了安装那一步，没想到一直卡着不动，还以为下错安装包了，又问 DeepSeek，说是下载时间长不可避免，也是要通过国外节点来下载某个程序。

### 替代方案

Ollama 还没下载好，只能先用 Python 下载嵌入模型，也搞了有半小时。

AnythingLLM 安装完成后又同步下载了千问的语言模型，通过 AnythingLLM 下载的千问也好久，一个多小时也还没好，折腾到最后愣是没搞出个结果。

### 总结

最后只能把这些安装包跟嵌入模型，拷贝一份到硬盘。本地部署不用开云服务会员，但是搞这些必要的平台还有工具，大语言模型很耗费时间。

下次再找一天时间来搞这些，看能不能搞成，主要是把这些流程打通，后面就轻松的多。

## 3月30日 - 继续探索

### dify 部署再次碰壁

前两天计划用 dify 部署 RAG，先是下载了 Docker 来配置 dify，安装完成 Docker 后还要配置 WSL2，搞了半天还不行。

后面发现是 BIOS 虚拟化没开启，BIOS 虚拟化搞了大半个小时，最后发现是电脑不支持。

### LangChain 部署

没辙，只能转头部署 langchain，这玩意更复杂，要写好大段代码，而且不是简单的复制即用，还需要自己改，把文件路径填上去。

安装顺序：

1. 安装 ollama
2. 下载 nomic-embed-text 嵌入模型
3. 下载 deepseek-r1:1.5b 大语言模型
4. 配置 langchain
5. 配置 python 运行环境

### 测试结果

配置完这些到测试阶段，文件路径还搞了十来分钟。搞定了文件路径，导入个测试文件，功夫不负有心人，终于成了。

为了进一步测试又导入自己的文件，也成了，不过生成有点慢，8G 的电脑运行这些模型也是意料之中。

导入了个 4k 的 txt，应该是四五十秒才导入完成，然后再测试，生成答案差不多 1 分钟。答案准确但不够精简，问一句答了 10 来句。

### 多文档测试失败

为了进一步测试，又导入了多个文档，显示界面不太一样的，后面发现根本就没完成向量化。

再使用原来单个文档测试，又不成了。按照 Deepseek 的指示修改了管理员权限，还把安全防护关闭了，又重新下载 python，情况还是一样。测试单个文件可以，多个文件又不行。

### DeepSeek 的建议

最后 Deepseek 都劝我放弃，让我改用 AnythingLLM 或者用大厂的云计算。

到这会已经 3 点多了，还有两个多小时下班，想着 AnythingLLM 应该安装完成部署就快了。

接上硬盘安装 AnythingLLM，没想到这次很快，不到半小时就安装完成。嵌入模型跟大语言模型都下载好，直接勾选就行。

到了测试阶段一直转圈，心想这配置估计又跑不动。测试三四次都返回错误，每次测试都得等好几分钟，到 5 点多都快临近下班了只得明天再搞。

### 网吧的再次尝试

最后越想越不对劲，那破电脑不行，我还不能换电脑吗，真是不甘心。

下班吃完晚饭后又跑去网吧尝试用 langchain 部署 rag，一开始还是比较顺利，几分钟安装完 python、ollama。

### 模型拷贝的教训

上周下载过的嵌入模型 bge-m3，正好硬盘有，想着能不能复制到网吧电脑使用。搞了好一会，发现不行，上次的嵌入模型没有把 ollama 整个文件拷贝到硬盘。

先是下载了 llama.3.2 3b 大语言模型，应该是十来分钟就下载好了，测试也没问题。硬盘的嵌入模型不能为我所用，只得又重新下载嵌入模型。

想着网吧下载应该很快，毕竟大语言模型 2GB 都不用太久，就选择 bge-large-zh 嵌入模型。

### 下载速度问题

这是极为错误的选择，虽然体量不大，不如 bge-m3 三分之二的空间。但是网吧这个时段算是人不少，虽然没有全部坐满，但是网速占用很严重，有时候只有几 k 的下载速率。

光是下载到 50% 都大半个小时，找了 Deepseek 说可以换国内清华镜像源再尝试下载，把正在下载的进程中断，输入清华镜像源代码，居然提示没有，被 DeepSeek 坑了。

虽然它还列举了其他办法，但是我又不想太折腾，就又按照原来的方式下载。这下可好，从 8 点半下载到 10 点左右才完成，中间下载进度回退了好几次。

### 当天的收获

下载完成又要把两个模型完整的拷贝到硬盘，拷贝到硬盘后又测试了怎么在网吧给电脑使用。前后折腾了 10 来 20 分钟，最后实在搞不来，只能先确保模型是在硬盘，下次有时间搞。

今天也不是什么都没收获，下次我就知道了，需要什么模型，先在自己电脑下载完再拷贝到硬盘。

网吧大厅那环境待着真难受，特意选的那一排没其他人坐，但是背后那一排四台机都抽烟。

## 经验教训

### 环境限制

- 网吧电脑重启会清空环境
- 个人电脑配置低（8G内存），运行大模型吃力
- BIOS 虚拟化不支持导致无法使用某些工具

### 工具选择

- Cherry Studio：入门友好，适合新手
- dify：配置要求高，需要 Docker + WSL2
- langchain：灵活但需要编程能力
- AnythingLLM：安装相对简单但下载耗时

### 模型部署

- Ollama 下载受国外节点影响，速度不稳定
- 嵌入模型和大语言模型要完整拷贝
- 先在自己电脑下载再拷贝到移动硬盘更高效

### 网络问题

- 网吧网络高峰期下载速度极慢（几 k/s）
- 国内镜像源可能不支持部分模型
- 下载进度可能回退，需要耐心等待
