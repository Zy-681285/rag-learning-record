# RAG 避坑清单（值得你记住的教训）

## 1. 网吧/公共电脑复用模型
❌ 只拷贝 `.ollama/models` 下的某个模型文件夹  
✅ 拷贝整个 `~/.ollama` 目录，包括 `blobs` 和 `models`，才能在其他电脑直接使用。

## 2. 文档编码
❌ 直接用 PowerShell/iconv 将 ANSI 转 UTF-8 无 BOM  
✅ 先转带 BOM 的 UTF-8，再转无 BOM；或者使用编码批量转换助手（注意流氓软件）。

## 3. 嵌入模型配置错误
❌ 在工作流中添加另一个嵌入模型（如 Qwen），会覆盖原来的 BGE-M3，导致检索失效。  
✅ 一个 RAG 系统只用一个嵌入模型，或者明确分开不同知识库。

## 4. VLLM 硬件要求
❌ 低配机器（2核2G、8核8G）强行跑 VLLM  
✅ VLLM 需要至少 8 核 16G + GPU（或大量 CPU 换时间），否则不如直接用 Ollama。

## 5. 修改 Prompt 后忘记回滚
❌ 调工作流时改了 Prompt，测试召回率突然下降，还以为是数据问题。  
✅ 修改前先备份原始 Prompt，或者每次只改一个变量。

## 6. 免费云服务器跑 RAG
❌ 阿里 ECS 免费实例（2核2G）装 Dify，访问不了或极慢。  
✅ 本地混合部署（向量库本地 + API 模型）比免费云更可靠。

## 7. 下载模型时被坑
❌ 在网吧高峰期下载 bge-large-zh （几 KB/s，回退多次）。  
✅ 在家或公司先下载好模型，整个 `~/.ollama` 拷到移动硬盘。

## 8. 多文档同时向量化失败
❌ 以为是权限问题，关闭安全防护、重装 Python 都没用。  
✅ 其实是嵌入模型不支持某些文档格式或编码，先确保每个文档都能单独向量化。

## 9. 幻觉问题归因错误
❌ 以为是大语言模型不行，换成 API 还是幻觉。  
✅ 先用 Reranker 提高检索质量，再考虑换模型。

## 10. 知识库内容冲突
❌ 同一信息出现在不同分块或不同知识库，导致答案不一致。  
✅ 整理知识库，尽量保持信息原子化、不重复。
