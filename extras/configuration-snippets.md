# 关键配置片段（基于 Dify + 无影云）

## 1. Dify 知识库分块设置（最终有效的一版）
- **分块大小**：500 字符
- **重叠**：50 字符
- **分段预处理**：去掉空行，合并短段落

## 2. 嵌入模型
- **主模型**：BGE-M3（通过 API 调用）
- **适用场景**：中英文混合文档

## 3. ChatFlow 检索节点配置（三路检索）
| 节点 | 绑定知识库类型 | 分块大小 | 检索模式 | 语义权重 | 关键词权重 |
|------|--------------|---------|---------|---------|-----------|
| 节点1 | 小分段库 | 300 | 混合 | 0.9 | 0.1 |
| 节点2 | 大分段库 | 800 | 混合 | 0.1 | 0.9 |
| 节点3 | Q&A 问答对库 | - | 向量 | 1.0 | 0.0 |

> 三个节点的结果合并去重后送入 LLM。
